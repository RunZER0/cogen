# Venture Twin Agent spec

## Purpose
A persistent venture-building agent that underwrites a real business before the founder commits capital, attacks the assumptions behind the business case, turns surviving ideas into an executable launch roadmap, and re-runs the model when material facts change.

## Canonical demo
A founder has KES 1.8m and wants to open a supermarket/minimart in Ruiru, Kenya. The system decomposes the idea into financial, demand, location, regulatory and execution assumptions; labels weak evidence; estimates break-even risk; refuses premature capital commitment; and creates evidence tasks and execution gates.

## Required tools / data
- Gemini 3.7 Flash
- Google ADK
- Gemini Google Search grounding for live research
- Firestore for persistent venture state in cloud mode
- Cloud Run for hosted API/UI

## Safety / truthfulness constraints
- Never present guessed facts as verified facts.
- Every externally asserted material fact must carry source provenance and a confidence level.
- Never fabricate licences, fees, laws, suppliers, professionals, addresses, quotes or official links.
- Do not turn an uncertain simulation into a fake probability of business success; report what was simulated and which inputs are weak.
- Require the user to approve irreversible legal/financial actions.

## Success criteria
1. Create and persist a venture from founder primitives.
2. Build structured assumptions with provenance and uncertainty.
3. Produce a reproducible financial stress test and probability range for operating break-even under the stated assumptions.
4. Block capital-commitment gates when critical assumptions are unresolved.
5. Turn an approved/conditional venture into a registration/compliance/sourcing/launch roadmap.
6. Apply a material change event and recompute downstream conclusions.
7. Run end-to-end without a model key in deterministic offline mode; switch to Gemini + Google Search when credentials are present.
